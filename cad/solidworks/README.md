# SolidWorks source model

This directory contains the SolidWorks parts and assemblies for the wheel-leg robot.

The assembly files depend on the part files in this same directory. Keep the relative layout intact when opening the assemblies.

## 中文说明

这里保存轮腿机器人 SolidWorks 零件和装配体。装配体依赖同目录下的零件文件，打开或重新定位装配体时请保持相对目录结构不变。

模型和装配体的使用应遵循其对应的许可证和来源说明。
